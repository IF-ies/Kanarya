---
description: Kanarya masaüstü penceresini kur (Electron) / Install the Kanarya desktop window
---
Şu komutu çalıştır / Run this command:

`node "${CLAUDE_PLUGIN_ROOT}/hooks/kanarya-hook.js" kur`

`${CLAUDE_PLUGIN_ROOT}` çözülmediyse eklentinin klasörünü `~/.claude/plugins` altında `kanarya-hook.js` adıyla bul.
If `${CLAUDE_PLUGIN_ROOT}` is not resolved, find the plugin folder under `~/.claude/plugins` by searching for `kanarya-hook.js`.
Bitince kullanıcıya kanaryanın ekranın sağ üstünde açıldığını, sağ tıkla ayarlara girilebildiğini söyle (kullanıcının dilinde).
